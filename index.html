01La idea

Una aplicación, varios servicios.

Un sistema distribuido divide una solución en componentes independientes que colaboran a través de una red. Cada parte tiene una responsabilidad clara, pero el usuario percibe una sola experiencia.

01

Separación
Cada servicio resuelve una tarea específica.

02

Comunicación
Los servicios intercambian datos mediante HTTP y REST.

03

Escalabilidad
Los componentes pueden crecer de forma independiente.

04Conclusiones

Más flexible.
Más preparado.

Separar la aplicación en servicios permite que cada componente evolucione sin detener todo el sistema. A cambio, aparecen retos de latencia, monitoreo y sincronización que deben gestionarse.

+Escalabilidad y mantenimiento independiente.
−Mayor complejidad de red y diagnóstico.
